# Data Placeholder

This directory is intentionally kept empty in the public paper repository.

The released paper experiments depend on transit schedule data for Fukuoka provided through Ekispert services. Because those source files are not currently redistributed here, only the code, figures, and released experiment outputs are published.

Expected contents for local reproduction typically include:

- station metadata
- line metadata
- timetable CSV files
- auxiliary boundary or map files used by the planner

If a redistributable sample dataset or a documented conversion pipeline becomes available later, it can be added here without changing the experiment code paths.
